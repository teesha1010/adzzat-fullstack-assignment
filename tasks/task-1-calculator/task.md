
# Task 1: Fix the Python Calculator

## Statement

The repository contains a Python calculator
with addition, subtraction, multiplication and
division operations.

The division operation currently produces
incorrect results for decimal numbers and
does not handle division by zero correctly.

Fix the division functionality.

Requirements:

1. Division must return accurate decimal results.
2. Division by zero must raise ZeroDivisionError.
3. Existing calculator operations must continue
   working.
4. Do not change existing function names.

## Environment

- Python 3.11
- Ubuntu Linux
- Pytest

## Difficulty

Easy

## Task Type

Language-driven
