
# Task 2: Improve User Registration

## Statement

The application currently allows users to
register without properly checking their
email addresses.

Improve the registration functionality so
that it meets the following requirements:

1. Valid email addresses should be accepted.
2. Invalid email addresses should be rejected.
3. Duplicate email addresses should not be
   accepted.
4. Email comparison should be case-insensitive.
5. Leading and trailing spaces should be
   handled correctly.
6. Existing successful registration behaviour
   should continue working.

Return a response containing a success status
and an appropriate message.

## Environment

- Python 3.11
- Ubuntu Linux
- Pytest

## Difficulty

Medium

## Task Type

Outcome-driven
